lilascii

turn your webcam into a really cool ascii live artwork



https://github.com/user-attachments/assets/b9ce2398-6780-4ef1-a796-d8fe861a006c



built with cv2

clone the repo, cd into it

then:
```
pip install opencv-python
```

and then your good to go! run with
```
python ascii.py
```
(or python3 on macos)
